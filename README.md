# Extracting and Visualizing Stock Data

## 📌 Description

This project focuses on **extracting historical stock and revenue data and visualizing it using graphs**. The data is collected using the **yfinance library and web scraping techniques**, and then visualized to analyze trends in stock prices and company revenue.

This project was completed as part of the **Coursera Data Science assignment**.

## 🚀 Project Tasks

* Extract Tesla stock data using **yfinance**
* Extract Tesla revenue data using **web scraping**
* Extract GameStop stock data using **yfinance**
* Extract GameStop revenue data using **web scraping**
* Visualize Tesla stock price and revenue data
* Visualize GameStop stock price and revenue data

## 🛠 Technologies Used

* Python
* Pandas
* yfinance
* BeautifulSoup
* Requests
* Plotly
* Jupyter Notebook

## 📊 Key Concepts

* Data extraction from APIs
* Web scraping using BeautifulSoup
* Data cleaning and preprocessing
* Data visualization with Plotly
* Financial data analysis

## 📈 Output

The project generates **interactive graphs showing historical stock prices and revenue trends** for:

* Tesla (TSLA)
* GameStop (GME)
